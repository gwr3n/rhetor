Rhetor

Rethor is an Integrated Modelling Environment that leverages pyopl, a Python library for parsing and solving OPL-like mathematical programming models using Gurobi or Scipy (Highs). pyopl supports a subset of Optimisation Programming Language (OPL) syntax for linear and mixed-integer programming.

What's the deal?

Decision intelligence is difficult not because optimisation software can't crunch numbers but because framing the right problem is hard.

When a logistics manager says "deliver efficiently" do they mean minimize transit time, cut cost, lower emissions, or improve on‑time reliability? This matters, beause each interpretation leads to a different optimisation problem.

The real challenge is translating messy human intent into a precise problem statement that an optimisation solver can process. In addition, converting the solver's output back into clear, actionable guidance is equally difficult.

Our goal is to make every step in this pipeline explicit and reliable so the optimisation you run actually solves the problem you intended.

We deliver on this promise by leveraging Rhetor, our state-of-the-art decision intelligence engine that blends GenAI and Automated Reasoning.
